# Как открыть сайт в интернет со своего компьютера

Инструкция для Windows. Сайт будет доступен по ссылке, пока открыто окно терминала
и компьютер включён и подключён к интернету. Устанавливать ничего не нужно:
Python и SSH уже есть в системе.

## Что происходит

```
браузер посетителя ──► https://xxxx.lhr.life ──► localhost.run ──SSH-туннель──► ваш компьютер
                                                                                   │
                                                                   tools/serve.py (порт 5173)
                                                                   отдаёт только файлы сайта
```

- `tools/serve.py` — маленький веб-сервер на Python. Отдаёт только страницы, стили,
  скрипты и картинки. Папки `.git`, `tools`, `src`, `README` снаружи не видны.
- [localhost.run](https://localhost.run) — бесплатный сервис: по SSH «пробрасывает»
  ваш локальный сервер в интернет и выдаёт публичную ссылку.
- `start-public.ps1` запускает оба и следит, чтобы туннель переподключался.

## Запуск

### Вариант 1: из VS Code (проще всего)

1. Откройте папку проекта в VS Code
   (в GitHub Desktop: **Repository → Open in Visual Studio Code**).
2. Откройте терминал: **Terminal → New Terminal** (или `` Ctrl+` ``).
   Он сразу откроется в папке проекта.
3. Вставьте и нажмите Enter:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start-public.ps1
   ```

### Вариант 2: из обычного PowerShell

Сначала перейдите в папку проекта — иначе PowerShell скажет, что файла не существует:

```powershell
cd C:\Users\Asus\Documents\GitHub\nosikov-portfolio
```

```powershell
powershell -ExecutionPolicy Bypass -File .\start-public.ps1
```

## Где ссылка

Через несколько секунд в терминале появится QR-код и строка вида:

```
xxxxxxxxxxxxxx.lhr.life tunneled with tls termination, https://xxxxxxxxxxxxxx.lhr.life
```

Ссылка `https://xxxxxxxxxxxxxx.lhr.life` — это ваш сайт. Её можно отправлять,
открывать с телефона (удобно через QR-код).

## Остановить

Нажмите `Ctrl+C` в окне терминала или просто закройте его. Сайт перестанет открываться.

## Что нужно знать

- **Ссылка меняется.** При каждом запуске — новая. Анонимный режим localhost.run
  может сменить её и во время работы: тогда в терминале появится новая строка
  `... tunneled with tls termination, https://...` — актуальна последняя.
- **Обрывы — это нормально.** Если сервис закроет соединение, скрипт напишет
  «Переподключаюсь через 5 секунд» и подключится снова сам.
- **Компьютер не должен засыпать.** В спящем режиме сайт недоступен.
  Параметры Windows → Система → Питание → «Переводить в спящий режим» → «Никогда»
  (на время, пока нужен доступ).

## Постоянная ссылка

- **localhost.run с аккаунтом** — бесплатно, адрес не меняется, но сайт по-прежнему
  работает только при включённом компьютере. См. https://localhost.run/docs/forever-free/
- **GitHub Pages** — сайт работает всегда, даже при выключенном компьютере, адрес вида
  `andrussha86.github.io/nosikov-portfolio`. Репозиторий → **Settings → Pages** →
  Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → **Save**.
  Для бесплатного Pages репозиторий должен быть публичным.

## Если что-то не работает

| Сообщение | Что делать |
|---|---|
| `Аргумент ".\start-public.ps1" для параметра -File не существует` | Вы не в папке проекта. Выполните `cd C:\Users\Asus\Documents\GitHub\nosikov-portfolio` и повторите. |
| `python` не найден | Установите Python с python.org (галочка «Add to PATH») и откройте терминал заново. |
| `ssh` не найден | Параметры Windows → Система → Дополнительные компоненты → добавить «Клиент OpenSSH». |
| Ссылка открывает ошибку 503 | Туннель переподключается или сменил адрес — возьмите последнюю ссылку из терминала. |
| Порт 5173 занят | Закройте другое окно с запущенным сайтом (или перезагрузите компьютер). |

## Посмотреть сайт только у себя

Без интернета, только на этом компьютере:

```powershell
python tools/serve.py
```

и откройте http://127.0.0.1:5173.
