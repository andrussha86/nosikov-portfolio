Как я веду проект

Один и тот же маршрут в PARQ и МетеоРитме: сначала понять людей, потом рисовать.

  1. АудиторияКто пользователь и в какой ситуации
  2. КонкурентыОбщие паттерны и слабые места
  3. РеференсыНастроение и визуальные решения
  4. JTBDCore Job, Growth, Desired Outcome
  5. User FlowКаждый шаг и edge case на схеме
  6. ВайрфреймыДетально, чтобы потом не двигать фреймы
  7. UIЦвет только там, где нужен акцент
  8. UI-kitКомпоненты, стили и состояния для разработки
  9. Готовый продуктМакеты, прототип и UI-kit уходят в разработку

PARQ — поиск и оплата парковок (B2C/B2B)

Сервис на стыке финтеха и городской инфраструктуры. Дипломный проект по специальности «Прикладная информатика».

  • Полный цикл: глубинные интервью, JTBD, User Stories для водителей и владельцев парковок.
  • User Flow с edge cases — ошибки оплаты, переполненная парковка — без тупиковых путей.
  • Интерфейс ML-прогноза занятости: пользователь выбирает парковку заранее.
  • B2B-дашборд с визуализацией выручки и загрузки.
  • UI Kit в Figma на Components, Auto Layout и стилях — точная передача в разработку.
